# TeamForge

TeamForge is a small student project platform where people can post ideas, find projects and request to join teams.

## What is included

- Home page with project cards
- Search projects by name, description or skill
- Filter projects by category
- Project details popup
- Join request interaction
- Create a project page
- Login and sign-up demo using browser localStorage
- Projects created by the user are saved in the browser
- Responsive layout for smaller screens

## Run it

No server or package installation is needed for the current version.

Open `index.html` in a browser. For a smoother local development setup, use VS Code with the Live Server extension.

## Note

This is a frontend demo. User accounts and projects are stored in localStorage, so the data only exists in the current browser/device.
